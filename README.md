# keeb-K1
This is my keyboard design for the KEEB program from Hack Club.

![Keyboard](photos/photo%2012.png)

This is my very first keyboard! I have designed it so that you can have 6 configurable keys for macros or any other thing, along with joystick for scrolling or for using it as a mouse.

This was my first time making a PCB and writting firmware. Even though I already have experience with CAD, I did learn a few new things while making this.

NOTE: This project is still in active development as I still haven't made it in real life. Also, The firmware is complete, but support for vial is still in the works. Thus, `vial.json` won't work.
